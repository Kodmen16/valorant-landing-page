# VANTA // Taktik rehber

Riot Games ile bağlantılı olmayan, VALORANT atmosferinden ilham alan bağımsız responsive web arayüzü.

## Özellikler
- Hash tabanlı sayfa geçişleri: ana sayfa, ajanlar, silahlar, haritalar, istatistikler, hakkında ve 404
- Ajan arama/rol filtresi ve yetenek modalı
- Silah arama/kategori filtresi
- Koyu/açık tema, mobil hamburger menü, loading ve sayfa geçiş animasyonları
- İstatistik ekranında sahte veri yerine Riot API entegrasyon notları ve form iskeleti
- Harici framework veya gereksiz kütüphane yok

`index.html` dosyasını statik sunucuda açarak çalıştırabilirsiniz. Gerçek istatistikler için formun gönderim akışını güvenli bir backend proxy'sine bağlayın; API anahtarını frontend'e koymayın.
